V8.2：分析工作台界面重设计
==========================

- 将左侧白色长按钮列表改为深色分组命令栏，保留“推荐一步”为唯一主操作。
- 低频操作使用紧凑双列，1080×720 和 Windows 高 DPI 下不再向下溢出。
- 棋盘增加深色舞台边框、加粗棋盘线、落子点、棋子阴影和双层棋圈。
- 推演回放控制移动到棋盘下方，正式棋局与推演沙盘状态持续可见。
- 右侧改为候选着、API评议、分析正文和运行状态四级分析工作台。
- 修复左右栏错误关闭 grid 传播的问题；实际内部使用 pack，现已固定栏宽，
  防止文本控件把右侧分析栏撑出窗口。
- 新增最小窗口布局回归检查，验证左右栏均位于可视范围内。
- 已配置 DeepSeek 等兼容 API 时，“AI代走”升级为“API代走”：Pikafish
  先生成三个候选、评分和主变化，API 再从候选白名单中选择。
- API 选着还要经过候选白名单和本地合法着双重校验；超时、空响应、
  非法着或格式错误都会安全回退 Pikafish 首选。
