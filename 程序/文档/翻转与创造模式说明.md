# 一键翻转与创造模式

更新：2026-10-27。

## 一键翻转

棋盘上方的“翻转棋盘”每点一次交换上下方向，旁边显示实际哪方在下。
例如你执红方，翻转到“黑方在下”，红子就在上方。执方和行棋轮次不变。

每次启动时，人机和联机默认己方在上，本地双人默认红方在下。
默认仍执红；换为执黑后，自动视角会让黑方在上。
首次手动翻转后，方向在本次运行期间保留；重开、悔棋、换引擎、换执方、
换模式和推演均不会覆盖。重新启动后恢复默认行为。
联机双方各自翻转，互不影响。AI 思考和回放时也可以翻转。

图片导入窗口也使用“翻转棋盘”。“图片下方”解释原图，“翻转棋盘”控制预览；
不要因为翻转预览就修改图片方向。预览的点击和黄色标记会同步翻转。
自动预览跟随“我执”的选择，应用后仍保留自动模式；手动翻转后固定该方向。
本地双人没有唯一玩家，其自动预览与主棋盘一致，仍为红方在下。

## 引擎记忆

成功启用的 Pikafish 或 Px0 会立即记录，下次启动按保存的参数恢复并进行短时试算。
恢复 Px0 失败会清理失败进程并尝试 Pikafish，成功后记录实际启用的 Pikafish并提示原因。
加载失败或取消不记录失败目标；保存失败则保留本次成功启用的引擎并提示。
配置保存在用户目录的 .xiangqi-coach/engine_settings.json；棋力与指导速度继续独立记忆。

## 创造模式

1. 在本地人机或双人棋局中点击“创造模式”。可以在电脑思考时进入。
2. “移动”：点选任意一方棋子，再点目标位置；目标有子时交换两枚棋子。
3. “添加”：选红方或黑方棋子，再点交叉点；该位置已有棋子时替换它。
4. “删除”：切换到删除工具后点棋子。编辑中暂时缺将、多子也不会崩溃。
5. 设置“轮到”红方或黑方。该设置决定继续时的行棋方，与玩家执方独立。
6. 点“应用并继续”。通过局面检查后开始新棋局；如果轮到电脑则自动应手。
7. 点“取消”或按 Esc，丢弃草稿，返回进入前的棋局。若原来轮到电脑，重新搜索。

应用成功后，编辑形成的局面成为新的对局起点，之前的走棋和悔棋历史清空。
后续悔棋最多回到这个起点。“残局 → 重置当前起点”恢复该起点；
“新棋局”或“恢复标准开局”恢复标准布局。

编辑期间保留玩家执方、引擎、棋力和指导速度。可以随时翻转、缩放。
无关对局操作暂时禁用，棋盘下方的指导和回放栏暂时收起以扩大编辑区域；
应用或取消后恢复。

草稿与正式棋局隔离，旧引擎和 API 回调不能写入新局面。
应用前检查将帅数量、棋子数量和位置、将帅照面及行棋方相关约束。
失败时显示具体原因，草稿保留供继续修改。静态检查不等于完整历史可达性或赛事裁判。

联机及连接过程中不可使用创造模式。推演、回放或图片导入尚未结束时，先退出相应操作。
