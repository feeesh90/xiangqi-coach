象棋指导棋 V8.3 · Windows Pikafish 分析工作台
============================================

这版是在 V7 极速版基础上继续改，不再自己造一套“假AI”。

离线棋力层：
    本地 Pikafish + NNUE

联网协作层（可选）：
    你自己的 OpenAI-compatible API

二者职责完全分开：
    Pikafish 决定怎么走
    API 复核候选方案、解读推演；点“API代走”时从Pikafish候选中优先选着

第一次运行：
    一键启动.bat

如果已有 V5/V6/V7 的 Pikafish，引导器会尝试复用。

API 设置：
    左侧 -> ☁ API设置

填写：
    完整 API URL
    模型名
    API Key

接口需要兼容：
    POST chat/completions
    choices[0].message.content

例如你自己的：
    DeepSeek兼容网关
    通义兼容网关
    OpenAI兼容网关
    本地模型API
    公司内部LLM网关

为了避免把象棋下坏：
    普通人机对手仍由 Pikafish bestmove 决定。
    点“API代走”时，Pikafish 先计算三个候选、评分和主变化，
    DeepSeek 等 API 再从候选白名单中选择一着。
    API 不能自创候选以外的着法；返回异常时自动采用 Pikafish 首选。

V8.1 交互改进：
    AI推演4步会逐步播放，可暂停、继续、上一步、下一步
    被将军时明确显示全部解将着，并标出可解将的棋子
    黑方AI回合可点“人工接管本回合”，替AI走一手后自动恢复
    大师棋谱导入使用临时库完整构建，中断不会破坏现有数据库

V8.2 界面改进：
    棋盘成为界面主视觉，左右固定为命令栏和分析工作台
    命令按“对局 / 分析工具 / 设置”分组，低频操作改为紧凑双列
    回放控制移动到棋盘下方，与普通分析状态分开
    候选着、API评议、正文和运行状态使用清晰的四级信息层次
    修复高 DPI 下右侧分析栏被文本区撑宽、窗口内容被截断的问题
    1080×720 最小窗口会执行布局冒烟检查

V8.3 界面重构：
    删除占满高度的左侧工具栏，改为顶部状态栏 + 棋盘主舞台 + 右侧分析卡
    对局高频操作集中在棋盘下方，设置与棋谱状态收进分析卡底部
    棋盘格始终保持正方形，不再随窗口比例被横向拉伸
    去除可能显示异常的装饰符号，保留简洁中文按钮

引擎设置：
    左侧 -> ⚙ 引擎设置

可调整：
    Threads
    Hash MB

分析模式底层已支持：
    go movetime
    go depth
    go nodes

当前UI默认仍使用固定时间模式，因为交互响应最快。

2026-10-17 更新：
    棋盘上方改为“翻转棋盘”，点击一次交换上下方向，执方不变。
    新增“创造模式”，可移动、交换、增加、删除双方棋子。
    应用后从编辑局面重新开始；取消或 Esc 恢复原棋局。
    联机中不能自由摆子；双方仍可独立翻转。
    “速度”更名“指导速度”，控制推荐和推演；电脑应手仍由“棋力”决定。
    大师搜索预算仍为 7000ms，性能试验不会自行改动难度档位。
    详细用法见“翻转与创造模式说明.md”。
    Px0 GPU 运行环境和配置见 engine/px0-gpu/README.md；
    实测与本机配置说明见“引擎提速实测_20261017.md”。

2026-10-18 更新：
    “翻转棋盘”旁新增“我执红方 / 我执黑方”，点击换方并重开当前起点。
    标准棋局回到开局；导入残局和创造模式棋局回到各自起点，旧历史清空。
    人机空闲时可换方；联机、双人、推演、编辑、忙碌或相关设置窗口打开时禁用。
    首次手动翻转后的显示方向继续保留；自动视角则跟随玩家执方。
    棋力和指导速度选择后立即保存，下次启动恢复最近的选择。
    偏好文件为用户目录下 .xiangqi-coach/ui_preferences.json。
    最近一次落子的棋子显示白圈，选中黄圈优先。

2026-10-19 更新：
    新增双方固定两点连续往返限制，适用于玩家、电脑、指导推演和局域网。
    双方各自同一枚棋子在固定两点之间连续往返两轮时，
    若当前方有其他基本合法走法，禁止完成第二轮的最后一着，并提示变招。
    如果当前方基本合法走法确实只有一着，即使形成重复也允许。
    单方往返、另一方变招、吃子中断及三个以上位置的循环不在本次限制内。
    不因循环判和或判负，不自动悔棋、重开。
    Pikafish、Px0 和 API 代走均按相同约束选择；PV 遇禁招会截断。
    联机协议升为第 2 版，联机两端需要同步更新并重新创建房间。
    本功能是项目自定义防往返规则，不是完整赛事长将、长捉裁判。

2026-10-27 更新：
    引擎设置会记住最后成功启用的 Pikafish / Px0，下次启动自动恢复并试算。
    旧配置首次更新仍默认 Pikafish；选择一次所需引擎后即可记住。
    恢复 Px0 失败会关闭失败进程，尝试 Pikafish，并提示回退原因；
    回退成功后记住实际启用的 Pikafish。两者均不可用时仍可操作界面和本地双人。
    引擎已成功启用但保存失败时，本次继续可用，并提示下次可能无法恢复。
    配置仍为用户目录下 .xiangqi-coach/engine_settings.json。
    人机和联机自动视角改为己方在上：执红时红在上，执黑时黑在上。
    本地双人自动视角仍为红方在下。手动翻转在本次运行内保留，重启恢复自动。
    图片导入预览继承自动或手动朝向；自动模式不会因应用残局而变成固定方向。
