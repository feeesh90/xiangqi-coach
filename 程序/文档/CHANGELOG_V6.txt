V6 修复
=======
1. 推演计算期间现在可以立即退出。
   - V5 的 busy 判断会直接拦截退出按钮。
   - V6 退出时会发送 UCI stop，并丢弃旧分析结果。
   - Esc 也可以立即退出推演。

2. 推演速度大幅提高。
   - V5 极致模式单轮最长 25 秒。
   - V6 推演专用时间：
     强 1.2 秒 / 很强 2.2 秒 / 极致 3.5 秒。
   - AI推演4步只做一次 Pikafish PV 搜索，不需要4次分别等待。

3. 普通指导棋也提速。
   - 强 3 秒 / 很强 6 秒 / 极致 10 秒。
   - 首选仍用单PV强搜；备选方案另用更短 MultiPV 搜索。

4. BAT 启动器重做。
   - 不再调用 py.exe / py launcher。
   - 使用 PowerShell 查找真正可用的 Python 3.11+。
   - 一键启动.bat 和 run.bat 强制 CRLF。
   - UTF-8 无 BOM。
   - BAT 内只保留 ASCII 命令，避免 cmd 编码解析问题。
   - 如果新旧版本放在同一目录旁边，可自动复用旧版本已下载的 Pikafish。

5. Engine STOP 修复。
   - V5 stop() 会等待 analyze() 的大锁，实际上不能中断搜索。
   - V6 使用独立写锁，可以立即给正在搜索的 Pikafish 发 stop。
