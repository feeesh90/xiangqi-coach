# V8.3 UI 重构验收记录

压过棋盘，且旧棋盘几何会按画布宽高分别拉伸。

- `README.txt`、`CHANGELOG_V8.3.txt`：记录新版布局。
- `outputs/象棋指导棋_V8.3_UI预览.html`：与真实程序一致的交互预览。

## 已验证 [V]

- 全量单元测试：12项通过。
- GUI启动冒烟：Pikafish就绪，27,369盘棋谱加载成功。
- 1080×720实测：分析卡右边界1062≤1080；操作区底边657≤720。
- 棋盘格宽高均为39.3067像素，比例断言通过。

工具只在操作发生时提供入口，不持续抢占视觉层级。
